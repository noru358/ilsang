# BACKGROUND_MINIMALISM_POLICY

Status: CANONICAL
Updated: 2026-09-09

## Goal

Preserve character acting, continuity, readability, and generation stability by treating background detail as optional rather than as a default sign of quality.

## Core rule

Use the lowest-sufficient visual context.

If the joke reads without a background, omit the background.

If one object communicates the setting, do not draw the room.

If a location is only incidental, use a flat/blank field or a minimal cue.

## Background levels

### BG0 — none

- blank, flat, or very simple field
- character/reaction only
- preferred default

### BG1 — one or two context cues

Examples:

- phone
- office desk edge
- pillow
- drink
- laptop
- shopping bag

The cue exists only because it carries story meaning.

### BG2 — minimal spatial hint

A few simple lines/shapes establish “office,” “home,” “cafe,” etc.

Use only when BG0/BG1 would cause genuine comprehension loss.

### BG3 — explicit environment

A more complete room/location.

Not a normal BODY default. Use only when the environment itself is the joke or the spatial relation is essential.

## Episode budget

For a normal six-BODY episode:

- default target: all six slides at BG0 or BG1;
- BG2: exception, preferably no more than two slides;
- BG3: normally zero.

This is a strong production preference, not a publish-blocking numeric gate. Story meaning can override it.

## Prop policy

No decorative filler.

A prop should do at least one of:

- establish necessary context;
- participate in the action;
- deliver the joke;
- support continuity.

Otherwise omit it.

## Establishing information

Do not repeatedly redraw a location after it has been established.

A single minimal establishing cue can authorize simpler subsequent panels.

## Cover

The COVER may be graphically richer than BODY, but should still avoid unnecessary scenery. Prefer one strong character/situation image plus clean negative space for title/lettering.

## QC question

Before accepting a background element, ask:

“If this disappears, does the reader understand the same joke?”

If yes, remove it by default.
