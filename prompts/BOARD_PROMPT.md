# BOARD_PROMPT

Status: BLOCKED UNTIL VISUAL AUTHORITY IS APPROVED

Use only after the project has an explicitly user-approved character/art system and production carrier.

## Inputs

- approved storyboard/copy
- approved production visual authority
- approved runtime carrier
- `BACKGROUND_MINIMALISM_POLICY.md`

## Output

One text-free 2×3 BODY master board for S01–S06.

Hard requirements:

- no readable text, labels, captions, SFX, panel numbers, logos, UI glyphs, or speech balloons with text;
- six panels correspond in order to the approved storyboard;
- same character identity across panels;
- no unplanned wardrobe/appearance drift;
- no accidental extra limbs/fingers/duplicate objects;
- physical contact only when storyboard-relevant;
- lowest-sufficient background context;
- no decorative asset clutter.

The board is a coherence batch. Do not design final lettering here.

Do not use any prior rejected character/style sheet as visual authority.
